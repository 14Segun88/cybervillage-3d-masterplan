## Архитектурная схема проекта

### Основные компоненты
1. **API-сервер** - Обрабатывает HTTP-запросы и предоставляет данные для клиентской части.
2. **World Builder** - Отвечает за генерацию и управление географическими данными.
3. **Layout Agent** - Управляет отображением и интерфейсом.
4. **Модуль обработки России (process_russia.mjs)** - Обрабатывает данные о регионах и городах.
5. **Клиентская часть (src)** - Содержит основные скрипты и стили для отображения интерфейса.
6. **Данные о городах (citiesData.js)** - Хранит информацию о городах.
7. **Данные о событиях (eventsData.js)** - Хранит информацию о событиях.
8. **Географические данные (russiaGeoData.js)** - Используется для отображения карты.
9. **Модуль звука (soundFx.js)** - Отвечает за воспроизведение звуков.
10. **Модуль интерфейса (ui)** - Содержит компоненты для отображения пользовательского интерфейса.

### Взаимодействие компонентов
- API-сервер предоставляет данные для World Builder и клиентской части.
- World Builder использует данные о городах и событиях для генерации контента.
- Layout Agent управляет отображением и взаимодействием между компонентами.
- Модуль обработки России использует географические данные для отображения карты.
- Клиентская часть использует данные из World Builder и Layout Agent для отображения интерфейса.
- Модуль звука обеспечивает аудио-поддержку в интерфейсе.
- UI-компоненты взаимодействуют с клиентской частью для отображения интерфейса.
